# Jazz Eclectic — band website

Static site for https://jazzeclectic.com (Brisbane jazz four-piece).
Design: "Late Set" — see the spec in the journal repo:
`journal/_system/docs/plans/2026-08-15-jazz-eclectic-website-design.md`.

- No build step. Open `index.html` or serve the root with any static server.
- Deploys on Netlify (Trent's account); contact form uses Netlify Forms.
- `_reference/` holds the approved design concept HTML — not deployed, kept for design intent.
- Photo masters live outside this repo in `../jazz-eclectic-media/` — repo carries web derivatives only.
